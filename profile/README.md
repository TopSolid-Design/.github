# TopSolid'Design

> TopSolid'Design keeps a named solid on one Windows desk: open the solid model, check the assembly tree, and leave the drawing views on the same design workspace.

## Four Beats

1. **Name the solid.** Give the TopSolid'Design solid model a short title before you mix sketches.
2. **Pin the live bodies.** Keep current parts on the TopSolid'Design design workspace and leave unused sketches aside.
3. **Read the tree.** Open TopSolid'Design assembly tree before you move a component that already has a view.
4. **Check the views.** Read TopSolid'Design drawing views before you archive a face.
5. **Close the loop.** Clear finished solids so the next TopSolid'Design visit does not start with a search.

## First Questions

**Does TopSolid'Design replace every other program?**
No. TopSolid'Design sits beside the CAM list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate TopSolid'Design profile.

**Will TopSolid'Design feel heavy on an older laptop?**
No. TopSolid'Design is meant to stay readable during a normal design session.

**What should a new user try first?**
One small TopSolid'Design solid today, then the same drawing views tomorrow.

**Do drawing views leave the solid model?**
No. TopSolid'Design drawing views stay with the TopSolid'Design assembly tree on the same workspace.

## Who Sits Down at TopSolid'Design

- **Solid model** — bodies stay on the TopSolid'Design solid model.
- **Assembly tree** — names stay with TopSolid'Design assembly tree.
- **Drawing views** — sheets stay on one TopSolid'Design workspace.
- **Shop office** — drafts and delivery files stay apart inside TopSolid'Design.
- **Shared desk** — each TopSolid'Design profile keeps its own pins.
- **Handoff** — the next person can read the TopSolid'Design note without a tour.

## Field Note

TopSolid'Design is easier to trust when the design workspace stays smaller than the folder it came from. A named solid shows what is active, the assembly tree shows what you will touch today, and the closing note tells the next person which drawing view changed.

## One Real Pass

Pick a part that already has a name. Open it in TopSolid'Design, keep only that solid on the design workspace, and finish one drawing view you can see.
